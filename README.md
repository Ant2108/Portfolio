# Trần Ánh Ngân — Personal Archive

Personal portfolio built with Next.js (App Router), TypeScript and Tailwind CSS.

```bash
npm run dev     # http://localhost:3000
npm run build   # production build
npm run lint
```

## Editing content

All content lives in two files:

- `src/data/portfolio.ts` — name, intro, availability, navigation, technology index, principles, learning journey, contact links, site URL.
- `src/data/projects.ts` — the project archive. Add an object to `projects` and it appears on the home page with its own page at `/projects/[slug]`.

Empty values are handled for you:

| Field | Empty value is shown as |
| --- | --- |
| `year` | `n.d.` (no date) |
| `githubUrl` | Repository — *forthcoming* |
| `liveUrl` | Live demo — *not deployed* |
| `contact.email` / links | *forthcoming* |

Search for `TODO` to find the placeholders that still need real values (domain, contact links, project years, databases used).

## Images

- `public/images/projects/*.svg` — illustrative engraved plates. Replace with real screenshots (`.png`/`.jpg`/`.webp`, ideally 16:10) and update `image` in `projects.ts`. Captions switch from "illustrative plate" automatically when the image is not an SVG.
- `public/images/profile/porfolio.jpg` — the portrait (set by `person.portrait` in `portfolio.ts`). It is cropped to 4:5 from the top, and a white background blends into the paper.
- `public/textures/paper-grain.svg` — the background grain.

### Regenerating the plates

The engraved plates are generated by two small scripts (no dependencies):

```bash
node scripts/generate-plates.mjs public/images            # main project plates + portrait
node scripts/generate-diagrams.mjs public/images/projects # technical diagrams in the project galleries
```

The diagrams were drawn from the actual code of the `franchise` and `SWP391` repositories — update them if the code changes.
